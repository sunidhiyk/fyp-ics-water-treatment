# Evaluation Results (Phase 7)

Generated by `python -m eval.evaluate` on `data/run1` (510 s of operation: normal
traffic plus five attack episodes). Evaluation unit is one second (tick); ground
truth is the device log's per-tick label. Reproduce with:

```bash
python -m net.generate_dataset --out-dir data/run1 --seed 42   # dataset
python -m detect.lstm.train --device-log data/run1/device_log.csv
python -m eval.evaluate
```

## Ablation — per-second precision / recall / FPR / F1

| Layer | Precision | Recall | FPR | F1 |
|---|---|---|---|---|
| DPI (rule) | 1.000 | 0.600 | 0.000 | 0.750 |
| NetFlow | 1.000 | 0.200 | 0.000 | 0.333 |
| LSTM | 0.929 | 0.520 | 0.032 | 0.667 |
| **Combined** | **0.958** | **0.911** | **0.032** | **0.934** |

The combined detection-in-depth system dominates every single layer on recall and
F1: no individual layer sees more than 60% of attack activity, while the
combination reaches ~91% recall at ~96% precision.

## Per-attack-class recall

| Layer | FDI | Command inj. | Flooding | Replay | Stealth |
|---|---|---|---|---|---|
| DPI (rule) | 100% | 100% | 0% | 100% | 0% |
| NetFlow | 0% | 0% | 100% | 0% | 0% |
| LSTM | 100% | 87% | 9% | 9% | 56% |
| **Combined** | **100%** | **100%** | **100%** | **100%** | **56%** |

Every attack class is covered by at least one layer. The two attacks the
protocol-aware layer cannot see — flooding (a flood of valid reads) and stealth (a
protocol-valid command from a compromised HMI) — are exactly the ones the NetFlow
and LSTM layers were added to catch.

## Detection latency (seconds to first alert)

| Layer | FDI | Command inj. | Flooding | Replay | Stealth |
|---|---|---|---|---|---|
| DPI (rule) | 0 | 0 | missed | 0 | missed |
| NetFlow | missed | missed | 0 | missed | missed |
| LSTM | 0 | 1 | 5 | 0 | 0 |
| **Combined** | **0** | **0** | **0** | **0** | **0** |

The combined system raises an alert within the first second of every attack
episode.

## Notes on the numbers

- **Stealth recall (56%) vs latency (0 s).** At the per-second level the LSTM
  flags 56% of the stealth episode's seconds, but its *first* alert lands at the
  episode's first second, so the episode is detected immediately. Per-second
  recall understates episode-level detection, which is 100% for every class.
- **Combined FPR (0.032).** The only false positives come from the LSTM firing on
  windows in the few seconds just after an attack ends, where its sliding window
  still overlaps attack data. This is an artifact of the strict per-second
  ground-truth convention (the tick is labelled normal even though the window
  still contains attack samples) rather than a spurious alarm during genuinely
  normal operation. DPI and NetFlow have a 0% false-positive rate.
